# Changelog

## 0.1.0 — 2026-11-06

First public release.

- Dedicated **APNG Image** source for OBS Studio on Windows x64.
- Native Delphi PNG decoding with statically linked RTL zlib.
- Alpha, partial frames, SOURCE/OVER blending and all APNG disposal modes.
- Adjustable playback speed from 1% to 1000%, looping and restart/resume controls.
- Premultiplied frame cache and frame-change-only texture uploads.
- OBS 32.x/33.x compatibility through DelphiOBS v0.2.0.
- 239 decoder test cases and an isolated D3D11 rendering probe.
