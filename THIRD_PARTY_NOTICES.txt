Third-party components
======================

DelphiOBS
---------
The plugin links the shared Delphi OBS API bindings from:
https://github.com/nalilord/DelphiOBS
Tested release: v0.2.0 (commit 950124534495f58b82344710655286b60dd318f6).
The bindings are licensed under GNU GPL v2. Their source and license remain
available in the upstream repository; they are not vendored here.

Delphi runtime
--------------
Windows builds use the Delphi RTL, including System.ZLib. Delphi compiler and
RTL source files are not included in this repository. A licensed Delphi Win64
compiler is needed to build the Windows plugin. Runtime packages are not used.

zlib
----
The Delphi 37.0 RTL used for validated Windows builds bundles zlib 1.3.1.
The optional Linux decoder tests use system libz through FPC's ZLib binding.
https://zlib.net/
